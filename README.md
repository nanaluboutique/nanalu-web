# Nanalu Boutique

A handmade-goods shop (sewn, with some knit/crochet) — sold ready-made and made-to-order via a visual fabric configurator. Built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Quickstart

Requires **Node 20+** and **npm**.

```bash
npm install      # install dependencies
npm run dev      # start the dev server → http://localhost:3000
```
